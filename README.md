# Wedding e-invitation (React + Vite)

## Run locally
    npm install
    npm run dev          # opens http://localhost:5173

## Customise
Edit `src/config.js` (names, date, venue, schedule, dress code, hotels, gifts, RSVP WhatsApp/email).
Colours live at the top of `src/styles.css`.

## Publish
    npm run build        # creates the dist/ folder
Upload `dist/` to Netlify, Vercel, Cloudflare Pages, GitHub Pages or any web host,
then share the link with your guests.
